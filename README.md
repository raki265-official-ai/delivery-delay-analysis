# Delivery Delay Analysis

## 📌 Project Overview

This  project analyzes delivery data to identify delayed deliveries, delivery performance, and route-related issues.

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* PYTHON
* SQL 
* Data Cleaning

## 📊 Key Analysis

* Total Deliveries
* On-Time Deliveries
* Delayed Deliveries
* Delay Percentage
* Route-wise Delivery Performance
* Delivery Status Analysis

## 🧹 Data Cleaning

* Removed exact duplicate records
* Compared raw and cleaned data
* Used route lookup data for analysis

## 📈 Dashboard

The dashboard provides a quick view of delivery KPIs, delay trends, and route performance using Pivot Tables and charts.

## 🎯 Objective

To understand delivery delays and create a simple data-driven dashboard that helps identify delivery performance issues.
